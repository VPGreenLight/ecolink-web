## Lượt trao đổi #1 — Sửa format phần địa chỉ bàn giao trên mobile tại Yêu cầu bàn giao
- **Prompt người dùng:** `phần địa chỉ bàn giao của phần yêu cầu bàn giao đang bị lỗi format ở mobile`
- **Phân tích & giải pháp:**
  - Tại `src/pages/recycler/Requests.tsx`:
    - Trong danh sách **Chờ bạn xác nhận**: chuyển header mỗi card từ `flex-wrap` thiếu `flex-1` sang `flex-col gap-2 sm:flex-row sm:items-start sm:justify-between sm:gap-3` với `min-w-0 flex-1` và `leading-snug break-words` cho địa chỉ (`h.address`), giúp địa chỉ dài không bị bóp hẹp hoặc xô lệch giá tiền ước tính trên màn hình nhỏ.
    - Trong mục **Lịch đã nhận**: bảng `<Table>` có nhiều cột `whitespace-nowrap` nên trên mobile cột `Địa chỉ` bị ép quá hẹp và phải cuộn ngang. Bổ sung giao diện danh sách card riêng cho mobile (`md:hidden`) hiển thị đầy đủ địa chỉ `break-words`, mã đơn, khung giờ, tiền ước tính và thao tác; giữ `<Table>` cho `hidden md:block` kèm `min-w-[220px] max-w-[340px]` ở cột `Địa chỉ`.
- **File thay đổi:** `src/pages/recycler/Requests.tsx`, `docs/2026-11-28.md`
- **Kiểm thử:** `npm run typecheck`, `npm run check`, `npm run check:routes`, `npm run build`

## Lượt trao đổi #2 — Khắc phục số liệu bị nhảy trên trang Tổng quan cơ sở thu mua (`/recycler`)
- **Prompt người dùng:** `/recycler tổng quan phần số liệu đang bị nhảy`
- **Phân tích & giải pháp:**
  - Tại `src/pages/recycler/Home.tsx`, khi đang tải dữ liệu từ backend (`liveAuth === true`), 4 thẻ KPI ban đầu hiển thị `0`, `0 kg`, `0 đ`, `0` rồi nhảy sang số liệu thật khi API trả về; đồng thời 4 biểu đồ hiển thị bộ số liệu mẫu fallback (`38, 46, 52...`, `Nhựa tái chế 124 kg`, `890.000 đ`) rồi nhảy sang số liệu thật.
  - Bổ sung state `loadingTx` (`initApiLoading(true)` và tắt ở `.finally()` của `fetchRecyclerTransactions`):
    - Khi `loadingHandovers` / `loadingTx` đang `true`, 4 thẻ KPI hiển thị skeleton giữ đúng chiều cao `h-7` (`leading-7`) thay vì nháy số `0`.
    - Khi đang tải, 4 biểu đồ hiển thị khung skeleton đồng bộ kích thước thay vì nháy dữ liệu mẫu fallback rồi nhảy sang dữ liệu thật.
- **File thay đổi:** `src/pages/recycler/Home.tsx`, `docs/2026-11-28.md`
- **Kiểm thử:** `npm run typecheck`, `npm run check`, `npm run check:routes`, `npm run build`
